# BuyAnyInsurance car insurance landing page

Static landing page for the "Don't carry the damage alone" campaign. No build step.

- `index.html`: page markup
- `styles.css`: styles
- `script.js`: lazy video loading and the WhatsApp quote form
- `vercel.json`: Vercel settings

Videos and images are served from the Higgsfield media CDN.

## Deploy on Vercel

1. In Vercel, choose **Add New > Project** and import this repository.
2. Framework preset: **Other**. Leave build and output settings empty.
3. Deploy. Every push to `main` redeploys automatically.

## Editing

- WhatsApp number: `WHATSAPP` in `script.js` and the footer link in `index.html`.
- Toll-free number: search for `800 765 429` in `index.html`.
